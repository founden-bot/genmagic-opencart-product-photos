# Changelog

## 1.0.0

- First release.
- Settings page (status, GenMagic API key, consent box) under Extensions > Modules.
- "GenMagic photos" panel on the admin product edit form, added with an OpenCart 4 event (no core file is changed).
- Five styles (White studio, Lifestyle scene, With a model, Flat lay, Seasonal), up to 300 characters of extra wishes, a model picker with estimated prices.
- Shows the cost of each photo and the balance left.
- Approved photos are added to the product's additional images. The main image is only replaced when the box is ticked.
